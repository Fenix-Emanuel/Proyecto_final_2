# FinanceFlow - Proyecto Final JavaScript

## Contexto
FinanceFlow es un simulador financiero para registrar ingresos y gastos de un negocio personal o emprendimiento.

## Funcionalidades
- Agregar transacciones.
- Guardar datos en LocalStorage.
- Cargar categorías desde archivo JSON usando Fetch.
- Filtrar transacciones por descripción y tipo.
- Ordenar transacciones por fecha o monto.
- Calcular balance, ingresos y gastos usando métodos de arrays.
- Mostrar gráfico con Chart.js.
- Mostrar mensajes visuales con SweetAlert2.
- Eliminar transacciones mediante delegación de eventos.

## Tecnologías
- HTML5
- CSS3
- Bootstrap
- JavaScript
- Fetch API
- JSON
- LocalStorage
- SweetAlert2
- Chart.js

## Importante
Para que Fetch funcione correctamente, abrir el proyecto usando Live Server.
